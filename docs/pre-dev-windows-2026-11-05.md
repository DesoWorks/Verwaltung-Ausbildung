# Pre-Dev unter Windows starten

Stand: 05.11.2026. Branch `pre-dev/verwaltung-2026-11-05`.

Dieser Branch ist der Teststand für den Arbeitsplatz. Er ist nicht `dev` und nicht `main`. Kein Deployment.

Linux-Chrome über `file://` ersetzt die Windows-Sichtprüfung nicht. Firefox und NVDA sind hier nicht gelaufen.

## Herunterladen

1. Den Branch auf GitHub öffnen: `DesoWorks/Verwaltung-Ausbildung`, Branch `pre-dev/verwaltung-2026-11-05`.
2. Code als ZIP laden und entpacken. Kein Login nötig, wenn das Repository öffentlich ist.
3. Keine Schul-PDFs liegen in diesem ZIP. Der Lehrplan-Kompass ist nur Dokumentation.

## Start

1. `index.html` in Edge oder Chrome öffnen. Kein Server und kein Internetzugriff nötig.
2. Das Rathaus liegt unter `module/rathaus.html`.
3. Darstellung einmal auf Hell, Dunkel, hohen Kontrast und große Schrift stellen.
