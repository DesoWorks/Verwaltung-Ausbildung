# TASKFLOW – Windows-Sichtprüfung

Stand: 05.11.2026. Lokaler Branch `feature/verwaltung-taskflow-2026-11-05`. Kein Push, kein Merge, kein Deployment.

Linux-Chrome über `file://` ersetzt diese Prüfung nicht. Firefox und NVDA sind hier nicht gelaufen.

## Start

1. Den Branch als ZIP holen oder den Ordner kopieren.
2. `module/rathaus.html` in Edge oder Chrome öffnen. Kein Server nötig.
3. Darstellung einmal auf Hell, Dunkel, hohen Kontrast und große Schrift stellen.

## Bürgerbüro

1. Bürgerbüro öffnen. B01 bis B04 starten.
2. Bei B04 nur Schritt 1 von 5 sehen. „Einordnung“ und „Antwort“ erst über die Schritte oder „Weiter“.
3. „Hilfen“ öffnen. Es darf keine Musterlösung und keine richtige Options-ID erscheinen.
4. „Fallakte“ öffnen, ohne dass gesetzte Antworten verschwinden.
5. Eine Antwort setzen, die Seite neu laden. Die Antwort und, nach einem Schrittwechsel, der Schritt sollen wieder da sein.
6. „Fall zurücksetzen“ löscht nur diesen Fall.
7. Lehrkraftansicht: die fünf Fälle bleiben getrennt. Die Musterlösung erscheint nicht in der Lernansicht.
